# АСУ ОТО «Перрон»

Прототип информационной системы для диспетчера оперативного техобслуживания воздушных судов.

Когда командир воздушного судна сообщает о дефекте, система в реальном времени подбирает ближайшего **по времени прибытия** сотрудника с нужной квалификацией, строит маршрут по графу перрона и показывает диспетчеру обоснованное предложение. Регламент ПАО «Аэрофлот»: инженер обязан быть у борта **не позднее чем через 15 минут**.

Ядро написано на **Python**. Состояние смены хранится в **SQLite**. Интерфейсы разделены по ролям и собраны на **Vue 3** без npm-сборки.

---

## Что нужно жюри за 2 минуты

1. Убедитесь, что на компьютере установлен **Python 3.11 или новее** (проверка — ниже).
2. Дважды щёлкните файл `start.bat` в корне проекта.
3. Дождитесь чёрного окна с адресами и автоматически открывшегося браузера.
4. Войдите как **admin / admin**.
5. Нажмите **«Войти как…»** у борта `VP-BKC`, отправьте заявку, вернитесь в админку и откройте вкладку **«Диспетчеризация»** → подтвердите назначение. Затем войдите как назначенный инженер и посмотрите его маршрут.

Остановить сервер: в окне `start.bat` нажмите `Ctrl+C`, затем любую клавишу.

| Что открыть | Адрес |
|---|---|
| Вход и ролевые экраны | [http://127.0.0.1:8000](http://127.0.0.1:8000) |
| Документация REST API | [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) |

Интернет для работы не нужен. После установки зависимостей система работает полностью офлайн.

## 1. Требования к компьютеру (Windows 11)

| Компонент | Нужно | Не нужно |
|---|---|---|
| ОС | Windows 11 (подойдёт и Windows 10) | — |
| Python | **3.11** или новее | Node.js, npm, Docker, внешняя СУБД |
| Браузер | Chrome, Edge или Firefox | — |
| Сеть | только для первой установки пакетов из PyPI | постоянный интернет |

Сторонние сервисы, облако и ключи доступа не используются. SQLite-файл создаётся сам при первом запуске: `data/ramp.db`.

### 1.1. Проверить, установлен ли Python

1. Нажмите `Win`, введите **PowerShell**, откройте «Windows PowerShell».
2. Выполните:

```powershell
py -3 --version
```

Ожидаемый ответ, например: `Python 3.11.0`. Подойдёт любая версия **3.11, 3.12 или 3.13**.

Если команда `py` не находится, попробуйте:

```powershell
python --version
```

### 1.2. Если Python не установлен

1. Откройте [https://www.python.org/downloads/](https://www.python.org/downloads/).
2. Скачайте установщик для Windows.
3. **Обязательно** отметьте пункт **Add python.exe to PATH** на первом экране установщика.
4. Нажмите «Install Now» и дождитесь окончания.
5. Закройте все окна PowerShell и откройте новое — иначе `PATH` не обновится.
6. Снова выполните `py -3 --version`.

Установку из Microsoft Store лучше не использовать: у неё часто ломается `PATH`. Берите официальный установщик с python.org.

## 2. Запуск сервера

Рабочая папка проекта — та, где лежат `start.bat`, `requirements.txt` и каталоги `backend` и `frontend`. Путь может содержать кириллицу (например, «Рабочий стол») — это допустимо.

### Способ А. Двойной щелчок — основной для демонстрации

1. Откройте папку проекта в Проводнике.
2. Дважды щёлкните `start.bat`.
3. При первом запуске скрипт:
   - создаст виртуальное окружение `.venv`;
   - установит зависимости из `requirements.txt` (нужен интернет только в этот момент);
   - откроет браузер на [http://127.0.0.1:8000](http://127.0.0.1:8000);
   - запустит сервер на порту **8000**.
4. Окно командной строки **не закрывайте** — это и есть сервер.

Повторные запуски быстрее: окружение уже создано, пакеты только проверяются.

Если Windows покажет предупреждение SmartScreen («Неизвестное приложение»):

1. Нажмите **Подробнее**.
2. Нажмите **Выполнить в любом случае**.

Файл `start.bat` — обычный текстовый скрипт из этого репозитория, он ничего не скачивает кроме пакетов из `requirements.txt`.

### Способ Б. Вручную в PowerShell

Этот способ удобен, если нужно видеть полный вывод установки.

```powershell
cd "C:\путь\к\папке\aeroflot"

py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

$env:PYTHONPATH = "$PWD\backend"
.\.venv\Scripts\python.exe -m uvicorn ramp.main:app --host 127.0.0.1 --port 8000
```

После строки `Uvicorn running on http://127.0.0.1:8000` откройте этот адрес в браузере.

Если PowerShell запрещает запуск скриптов и ругается на `Activate.ps1` — не активируйте окружение через `activate`. Вызывайте интерпретатор напрямую: `.\.venv\Scripts\python.exe`, как в командах выше. Так работает и `start.bat`.

### Способ В. Если порт 8000 занят

```powershell
$env:PYTHONPATH = "$PWD\backend"
.\.venv\Scripts\python.exe -m uvicorn ramp.main:app --host 127.0.0.1 --port 8010
```

Затем откройте [http://127.0.0.1:8010](http://127.0.0.1:8010).

## 3. Роли и демонстрация

| Роль | Логин | Пароль | Что видит |
|---|---|---|---|
| Администратор / диспетчер | `admin` | `admin` | CRM: мониторинг, CRUD, карта, «Войти как…» |
| Инженер | `E-01` … `E-08` | `demo` | Свой статус, активный вызов, только свой маршрут |
| Борт | `VP-BKC`, `RA-89142`, … | `demo` | Карточка ВС и форма заявки |

### 3.1. Сквозной сценарий для жюри

1. Войдите как **admin / admin**.
2. На вкладке **Мониторинг** видно, кто свободен и кто на задаче.
3. Нажмите **«Войти как…»** у борта `VP-BKC`. Откроется пустой экран кабины.
4. Выберите неисправность и нажмите **«Отправить заявку»**.
5. **Вернуться в админку**: заявка уже назначена автоматически. На вкладке **Диспетчеризация** виден маршрут. При необходимости нажмите **«Отменить заявку»**.
6. Снова **«Войти как…»** у назначенного инженера: на карте только его маршрут до борта.

Вкладки **Персонал** и **Борта** — изменение квалификаций, допусков, статусов и стоянок через модальное окно. Новый сотрудник и новый борт сразу получают свой аккаунт с паролем `demo`.

Вкладка **Сценарии** — десять кнопок «Быстрый запуск сценария». Каждая перестраивает SQLite (позиции, статусы, перекрытия дорог) и открывает карту, чтобы жюри сразу видело новую расстановку. Сам подбор запускается кнопкой **«Подобрать исполнителя»**.

### 3.2. Перетаскивание на карте диспетчера

На вкладке **Диспетчеризация** маркеры инженеров по-прежнему перетаскиваются. Координаты пишутся в SQLite; незакрытый подбор пересчитывается.

### 3.4. Контрольные сценарии на карте

Войдите как **admin / admin** → вкладка **Сценарии** → **«Быстрый запуск сценария»** у TS-1 или TS-7. Карта перерисуется под выбранную расстановку. Затем вкладка **Диспетчеризация** → **«Подобрать исполнителя»**.

Алгоритм Дейкстры и регламент 15 минут проверяются в `pytest`: дважды щёлкните `run-tests.bat`.

## 5. Архитектура

```
┌─────────────────────────────────────────────────────────────┐
│  Vue 3     login / кабина ВС / инженер / CRM админа         │
│            без npm, компоненты в frontend/js/spa.js         │
└───────────────────────────┬─────────────────────────────────┘
                            │  REST + cookie-сессия
┌───────────────────────────▼─────────────────────────────────┐
│  FastAPI   роли, impersonation, CRUD, диспетчеризация       │
└───────────────────────────┬─────────────────────────────────┘
          ┌─────────────────┴─────────────────┐
          ▼                                   ▼
   SQLite + SQLAlchemy                 ramp.core
   data/ramp.db                        Дейкстра и регламент 15 мин
   справочники + смена                 без SQL внутри алгоритма
   seed_db() при пустой базе
```

Почему так:

- **Python в ядре** — алгоритмы, модели и тесты можно защищать отдельно от интерфейса. `pytest` гоняет всю предметную логику без браузера.
- **FastAPI** — типизированный контракт, автодокументация на `/docs`, проверка входных данных через Pydantic.
- **Один процесс** — сервер отдаёт и API, и статику. Жюри не настраивает CORS и не поднимает второй сервер.
- **Полный снимок состояния** в каждом ответе. Клиент не склеивает частичные обновления и не дублирует правила предметной области.

### Что считает сервер

- требуемую квалификацию по типу неисправности;
- пригодность каждого сотрудника смены (допуск, занятость, перерыв, конец смены);
- кратчайший **по времени** путь пешком и на спецтранспорте (алгоритм Дейкстры на двух подграфах);
- заезд на склад ЗИП, если дефект требует инструмента;
- ETA, запас до нарушения регламента, доказательство оптимальности;
- сравнение с выбором «ближайший на карте»;
- текст уведомления в корпоративный бот.

### Что делает браузер

- рисует узлы, рёбра, борта, технику и людей по координатам из ответа;
- рисует готовую ломаную маршрута;
- принимает клики, выбор в форме и перетаскивание маркеров;
- показывает строки, которые уже сформулировал сервер.

## 7. REST API

Базовый префикс: `/api`. Тело запросов и ответов — JSON. Любое действие диспетчера возвращает **полный** снимок смены: клиенту не нужно помнить предыдущее состояние.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/reference` | Справочники и карта. Запрашивается один раз при загрузке |
| `GET` | `/api/state` | Текущая смена |
| `POST` | `/api/calls` | Зафиксировать вызов и получить предложение |
| `POST` | `/api/calls/current/recalculate` | Пересчитать с другой политикой |
| `POST` | `/api/calls/current/commit` | Подтвердить назначение и отправить уведомление |
| `POST` | `/api/calls/current/cancel` | Отменить открытый вызов |
| `POST` | `/api/employees/{id}/position` | Новые координаты сотрудника |
| `POST` | `/api/scenarios/{code}/load` | Перестроить базу под контрольный сценарий |
| `POST` | `/api/reset` | Вернуть исходную расстановку |
| `GET` | `/api/health` | Проверка карты и версия |

Пример вызова без интерфейса (сервер должен быть запущен):

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/health
```

Интерактивная песочница: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

Сеанс один на процесс сервера. Два окна браузера показывают одну и ту же смену — так удобнее на демонстрации. Перезапуск `start.bat` сбрасывает память процесса и поднимает исходную расстановку.

## 9. Типичные проблемы при запуске на Windows 11

**«Python не найден» после установки.**  
Закройте все окна терминала и откройте новое. Если не помогло — переустановите Python с python.org, включив **Add python.exe to PATH**.

**PowerShell пишет про Execution Policy и `Activate.ps1`.**  
Окружение активировать не обязательно. Используйте `start.bat` или вызывайте `.\.venv\Scripts\python.exe` напрямую.

**Браузер показывает «не удаётся получить доступ к сайту».**  
Сервер не запущен или окно `start.bat` закрыли. Запустите скрипт снова и дождитесь строки `Uvicorn running on http://127.0.0.1:8000`.

**Страница открылась, но карта пустая и сверху красная плашка «Сервер недоступен».**  
Файл `frontend/index.html` открыли с диска (`file://`), а не через сервер. Нужен адрес `http://127.0.0.1:8000`.

**Порт занят (`[Errno 10048]` или `address already in use`).**  
Либо закройте предыдущее окно сервера, либо запустите на другом порту — см. способ В в разделе 2.

**`pip` не ставит пакеты, нет интернета.**  
Первая установка требует доступ к [https://pypi.org](https://pypi.org). Если пакеты уже стоят в `.venv`, повторный запуск `start.bat` работает офлайн.

**Антивирус удаляет `.venv` или блокирует `python.exe`.**  
Добавьте папку проекта в исключения или поставьте пакеты ещё раз: удалите каталог `.venv` и снова запустите `start.bat`.

**Кириллица в пути.**  
Рабочий стол OneDrive с русским именем поддерживается. Не переносите проект в путь с кавычками или символом `&`.

## 10. Как устроен подбор исполнителя

Кратко — чтобы было что показать у доски.

1. Диспетчер указывает **борт** и **тип неисправности**.
2. По справочнику дефектов система выводит требуемую квалификацию (B1, B2, A, NDT, STRUCT), приоритет, нужен ли склад ЗИП и обязателен ли спецтранспорт.
3. Оценивается **вся смена**, не один «ближайший». Непригодные получают причину отказа в протоколе.
4. Для пригодных строится маршрут. Вес ребра — **время**, не метры: на подъездных полосах транспорт едет медленнее, пешеходные проходы транспорту закрыты.
5. Среди уложившихся в 15 минут выбирается минимальный ETA. При равенстве — явный тай-брейк (загрузка за смену, табельный номер).
6. Проверяется инвариант: ни один доступный кандидат не прибывает раньше выбранного.
7. Диспетчер подтверждает. Сотрудник переводится в путь, техника занимается, формируется текст уведомления.

Если никто не укладывается в регламент, назначение не выдаётся. Система показывает эскалацию: снять с перерыва, вытеснить с менее приоритетной заявки, вызвать резерв.

Подробная постановка задачи, критерии оценки и разбалловка — в `REQUIREMENTS.md`.
